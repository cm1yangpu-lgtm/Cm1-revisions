# Révisions CM1 — LFS Yangpu

Site statique de révisions pour les classes de CM1.

## Ajouter une activité

Dépose ton fichier HTML dans le dossier de la matière concernée (`histoire/`, `sciences/`, etc.). Ensuite, ajoute un lien vers ce fichier dans l'`index.html` de la matière. Si ton activité utilise des images/CSS/JS séparés, conserve-les dans un sous-dossier dédié ou dans `assets/`.

Le projet est conçu pour GitHub Pages : pas de serveur ni de backend nécessaire.
